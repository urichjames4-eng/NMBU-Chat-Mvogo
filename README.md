# NMBU Chat Mvogo

This project contains a mobile-style chat app built with Next.js and Tailwind CSS.

## Local development

```bash
npm install
npm run dev
```

Open http://localhost:3000

## Deploy on Vercel

1. Push this repository to GitHub
2. Open https://vercel.com
3. Import the repo
4. Use the default Next.js configuration
5. Deploy

## Notes

The app includes:
- NMBU / SMS / FLASH mode selector
- Sticker pack store
- Search assistant panel
- Mock call flow
- Mobile-first design
